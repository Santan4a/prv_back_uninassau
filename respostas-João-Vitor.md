1- O Git init é comando que inicia, criando o repositório e o git clone copia um repositório que já existe.
2- O comando git status é responsável por permitir a visualização do estado projeto.
3- Git add é para incluir as alterações e o commit para salvar as alterações.
4- Git fetch busca alterações no repositório sem alterar o local, já o git pull além de buscá-las, já às aplica.
5- Branch é uma ramificação do projeto, utlizada pois permite alterar o código sem interferir diretamente no código principal.
6- Uma solicitação para que as mudanças alteradas, sejam implantadas em outras branchs no projeto.
7- A branch de origem é onde se fazas alterações e a branch de destino é aque recebe as alterações.
8- Irá ocorrer um conflito.
9- Serve para dizer ao git quais arquivos não precisam ser enviados ao repositório.
10- Serve para explicar sobre o projeto e apresentar informações importantes do mesmo.
